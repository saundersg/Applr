# GeomSliceBand

The geom behind
[`geom_slice()`](https://saundersg.github.io/Applr/reference/geom_slice.md)
when `band` is requested: a translucent ribbon between the two edge
slices, with each edge drawn as an ordinary slice line. Like
[GeomSlice](https://saundersg.github.io/Applr/reference/GeomSlice.md),
`alpha` styles the ribbon, not the lines.

## Usage

``` r
GeomSliceBand
```

## Format

An object of class `ggproto`, inheriting from `GeomSlice`.
